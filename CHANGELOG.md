# Changelog

## 2.0

- First GitHub-ready public beta source release.
- First-run language now follows Android: Dutch system language selects Dutch; all other system languages select English.
- A manual NL/EN choice remains stored and takes precedence afterwards.
- Removed `Copy diagnostics` / `Diagnose kopiëren` from the visible overflow menu.
- Five taps on `Gemaakt door KreeZiE` / `Made by KreeZiE` copy a compact support diagnosis.
- Copy confirmation Toast is `Diagnose gekopieerd` / `Diagnosis copied`.
- Startmute explanation updated to describe the Bluetooth connection being established.
- Compact support diagnosis retains device, route/HFP, Startmute and latest-status information.
- Existing PAUZE/PAUSED handling during phone and supported VoIP calls remains unchanged.
- Version-number easter egg updated to build 80.

No intentional changes were made to the production HFP/SCO routing logic compared with 1.9.9.
